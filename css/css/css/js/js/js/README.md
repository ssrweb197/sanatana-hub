# Sanatana Hub — Premium Spiritual & Educational Platform

A modern, high-performance website build designed for timeless wisdom and digital learning.

## Architecture

- **Vanilla Technology**: HTML5, Modular CSS3, Vanilla JS. No dependencies or npm frameworks required.
- **Styling Separation**: Clear isolation between core styles (`style.css`), layouts (`responsive.css`), and animations (`animations.css`).
- **PWA Ready**: Manifest integration included for mobile app bookmarking.

## Assets Directory Setup
Place images, logos, and custom graphics in `assets/images/`, `assets/icons/`, and `assets/logo/`.
